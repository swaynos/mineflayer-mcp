This file tracks the 10-epic structure used by Epoch 5 nano-tier validation.
Canonical thresholds and execution rules are in `SPEC.md`.

## Epics

1. Quick status reads
2. Single-verb actions
3. Implicit multi-step ("find X")
4. Explicit multi-step ("do X then Y")
5. Block-interaction disambiguation
6. Inventory reasoning
7. Entity targeting
8. Survival response
9. Refusal / clarification
10. Ambiguity traps
